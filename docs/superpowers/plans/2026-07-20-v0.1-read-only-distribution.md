# v0.1 Read-only Distribution Implementation Plan

**Goal:** turn Product 1 into an installable read-only release candidate without widening the OPNsense tool
surface.

## Task 1 — configuration UX

1. Add failing tests for platform default paths, missing-default fallback, private atomic creation, overwrite
   refusal, fixed diagnostics, and secret non-disclosure.
2. Add a small `configure` CLI with injectable terminal I/O. Secrets are masked and never accepted as flags.
3. Make runtime discovery use the default file only when it exists; explicit bad paths still fail closed.
4. Run focused configuration, application, stdio, and installed-package tests; review and commit.

## Task 2 — package and client adapters

1. Add failing contract tests for publishable npm metadata, clean tarball contents, `server.json`, Codex and
   Claude plugin manifests/marketplaces, and current OpenCode/Kimi snippets.
2. Add npm/Registry metadata and generate the repo plugin structure with the official plugin scaffold rules.
3. Rewrite README quick start around configure-once plus client-native installation. Keep tested facts and
   unverified recipes visibly separate; update CONTRIBUTING with one bootstrap and the evidence ladder.
4. Pack and install the exact tarball with scripts disabled, validate manifests, and smoke every locally
   installed client that has a non-LLM connection probe; review and commit.

## Task 3 — final platform and release gates

1. Add Windows ACL implementation/tests and a `windows-2025` workflow that uses a path containing spaces and
   the generated npm `.cmd` shim against the synthetic HTTPS target.
2. Run Node 22 `npm run verify`, both MCP conformance versions, provenance, license, `git diff --check`, and
   `npm pack --dry-run`/installed-tarball inspection.
3. Run the supported client smokes and record exact versions. Do not claim Kimi or native Windows until their
   evidence exists.
4. Request independent code review, create atomic local commits, and stop before push, npm publication, MCP
   Registry publication, or release creation unless the owner explicitly authorizes those actions.
